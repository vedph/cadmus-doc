# Import

Although you are free to create a Cadmus database in any way, importing Cadmus data from other resources, especially when low-structure, mostly happens via the [Proteus framework](https://myrmex.github.io/overview/proteus/).

For instance, we might import a flat set of data from a spreadsheet into a highly-structured Cadmus database. As real-world examples you can see:

- for Word sources: the [BDM project](https://github.com/vedph/cadmus-bdm-tool).
- for Excel sources: the [TES project](https://github.com/vedph/cadmus-tes).

Any type of resource can be used as input, even plain text.

Additionally, some imports are available within the [editor UI](ui-import) itself.

>For importing taxonomies, see the section about [thesauri](../models/thesauri.md#editing-thesauri).
