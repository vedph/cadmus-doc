# Data Migration

Migration functionality in Cadmus refer to both data [import](migration/import.md) and [export](migration/export.md).

While nothing stops you from just importing data into the standard MongoDB database used by Cadmus, many existing components and procedures exist to satisfy the typical requirements of data import and export.

Most of the migration functions are available from the [Cadmus CLI tool](../tools/cadmus-tool.md).
